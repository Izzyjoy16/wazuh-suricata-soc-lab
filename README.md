# Integrated SOC Monitoring Lab: Wazuh + Suricata

## Project Overview

This project demonstrates a small Security Operations Center (SOC) monitoring workflow by integrating Suricata network intrusion detection events with Wazuh security monitoring.

## Objectives

- Generate network detection events using Suricata.
- Collect Suricata JSON events with Wazuh.
- Decode events and match them against Wazuh detection rules.
- Verify that matched events are recorded in Wazuh alerts.
- Document the configuration, testing process, and evidence.

## Tools Used

- Kali Linux
- Suricata 8.0.7
- Wazuh 4.14.8
- JSON / EVE event format
- jq
- Git and GitHub

## Lab Workflow

1. Analyze a sample DNS packet capture with Suricata.
2. Generate a custom DNS detection for `www.example.com`.
3. Configure Wazuh to monitor Suricata JSON events.
4. Test event decoding and rule matching with `wazuh-logtest`.
5. Verify that Wazuh records a matching alert in `alerts.json`.

## Detection Validation

The custom Suricata signature was:

`LAB DNS query for www.example.com`

Wazuh successfully decoded the JSON event and matched rule ID `86601`, producing the description:

`Suricata: Alert - LAB DNS query for www.example.com`

The event was verified in Wazuh's alert log after appending a test event to the temporary file `/tmp/suricata-wazuh-test.json`.

**Important:** The final end-to-end test used a temporary copy of an alert generated from a historical sample PCAP. It demonstrates event collection and rule matching; it does not represent a live attack or prove that the temporary test event was generated by live network traffic.

## Evidence

Screenshots and supporting findings will be stored in the `evidence/` and `report/` directories.

## Security and Scope

This is a controlled local lab. The sample PCAP contains historical traffic. No claim is made that the tested event represents a current threat or that traffic was blocked.
